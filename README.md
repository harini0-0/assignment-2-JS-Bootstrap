# Airbnb Listings Demo

This project displays the first 50 Airbnb listings from a JSON dataset using JavaScript Fetch API and async/await.

## Features

- Responsive Bootstrap layout
- Dynamic listing rendering
- Search functionality
- Host information with photos
- Amenities badges
- Hover card animations

## Technologies Used

- HTML
- CSS
- Bootstrap 5
- JavaScript (Fetch API + Async/Await)
